Install Legion Tracker

Put the tracker on your home screen like a normal app.

Android · Google Chrome
  1. Open the published GitHub Pages website directly in Chrome (not inside WhatsApp, Facebook or the GitHub app).
  2. Tap the ⋮ menu in the top-right corner.
  3. Choose Install app or Add to Home screen.
  4. Confirm the installation. The Legion Tracker icon will appear on your home screen.
iPhone · Safari
  1. Open the website in Safari.
  2. Tap Share.
  3. Choose Add to Home Screen, then tap Add.
Computer · Chrome or Edge

Use the install icon in the address bar, or open the browser menu and choose Install Legion Tracker / Install this site as an app.

If the install option is missing, make sure the website is the HTTPS GitHub Pages address, all app files are in the repository's published root, and the page has been opened online at least once. Some in-app browsers do not support app installation.
